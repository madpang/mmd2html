Ordered list with a nested unordered list

Ensure the VM is powered off, then:

  1. Open **virt-manager**,
  2. Select the VM and open **Details**,
  3. Click **Memory** tab,
  4. Enable **Shared memory** checkbox,
  5. Apply changes;
  6. Click **Add Hardware** button -> select **Filesystem**,
  7. Configure:
    • **Driver:** `virtiofs`
    • **Source path:** `/mnt/datastore`
    • **Target path:** `datastore`
    • **Access mode:** `Passthrough`
  8. Apply changes.
